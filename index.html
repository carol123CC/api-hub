API 中转站用户操作手册

欢迎使用 API 中转站！本手册将帮助您快速上手，通过统一接口调用多个 AI 模型服务。

第一步：注册与登录

1访问 api-hub.example.com 点击注册按钮
2填写邮箱地址并设置密码，或使用第三方登录
3验证邮箱后即可登录，新用户赠送 $5 体验金

第二步：获取 API 令牌

1登录后进入「令牌管理」页面
2点击「创建令牌」，填写令牌名称、勾选可用模型
3设置额度限制（每日/每月消费上限）和过期时间
4创建成功后复制密钥（格式：sk-xxxx...xxxx），请妥善保管

第三步：调用 API

所有模型均通过 OpenAI 兼容接口调用，只需修改 base_url 和 model 参数：

curl https://api-hub.example.com/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer sk-YOUR-TOKEN" \ -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好"}]}'

第四步：充值与管理

进入「钱包管理」页面，可通过在线支付充值或使用兑换码。在「数据看板」查看用量统计和成本分析。
